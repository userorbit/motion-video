# Interview: anchor the film before building

Aim for a strong first complete film by resolving the creative decisions up front. “One pass” means one settled brief followed by autonomous production and internal review, not a promise of perfect output or permission to skip verification.

After quick discovery, summarize what you know from the request, product and supplied references. Ask only for missing decisions; do not ask the user to repeat themselves. Name their real features and assets in the options. A discovered mascot is a candidate, not a decision to include it.

Use AskUserQuestion when available (at most 4 questions per call, 2–4 options, multiSelect where appropriate). Otherwise use the available question tool within its limits, or ask a short numbered set in chat. Put a concrete recommendation first. Allow free-text answers and asset paths or links. Group related decisions, and split only when the interface requires it. Do not send the entire question bank as a survey.

## First round: the creative anchor

Ask these missing decisions together, with short examples drawn from discovery:

| Decision | Ask |
|---|---|
| Audience and result | Who is watching, what problem should they recognize, and what ONE thing should they remember or do? Suggest a one-sentence promise backed by the product. |
| Destination and scope | Where will it play, how long, and in which aspect ratio? Does it loop or end on a CTA? Suggest a format from the destination; record exact CTA/URL if used. |
| Story and proof | Which 1–3 features or user journey must it show, in priority order? What real result, approved metric or quote proves the promise? What must stay out? |
| Brand carrier | Use the existing mascot, define a new character for this film, animate the logo/wordmark, or use UI only? Offer a new character only as an explicit creative choice; never silently invent one. |

A useful anchor reads: “For <audience> struggling with <problem>, show <real journey> so they remember <promise> and <action>; <brand carrier> guides the change from <before> to <after>.”

## Second round: define the chosen direction

Only ask the branches that apply. Combine related fields into a few answerable questions, not a separate question for every attribute.

### Mascot or character (if chosen)

Ask the user to define the mascot, even if the asset already exists; skip details already supplied or unambiguously visible in its reference.

- **Identity and source:** Which character and asset/reference path or link? Existing brand mascot or a new film-specific character? For a new one, what species/object, silhouette, proportions, face, palette/material and signature accessory define it? Offer 2–3 brand-compatible concepts if the user wants help choosing. Distinguish fixed traits from choices the user delegates.
- **Personality and motion:** Give 2–3 traits, its role (guide, helper, user stand-in, or cameo), signature gesture, and allowed expressions/poses. What should it never do? Does it speak? If yes, settle language and voice direction with the audio question.
- **Visual treatment and continuity:** Use the supplied style or choose flat/vector, illustrated 2.5D, or 3D as appropriate to the brand. Define relative size beside the UI, entry/exit, and its story job: what does it do in the opening, the key feature moment and the ending? Keep identity, colors, proportions and accessories consistent across scenes.

For an existing mascot, preserve its reference and do not redesign it. For a new one, record the user's definition or explicit delegation before creating the asset. If an asset cannot be accessed or the chosen treatment cannot be produced with available tools, explain the gap and ask for an accessible source or a feasible alternative. Do not silently swap in a different character. The mascot supports the product action and never obscures the UI or copy.

### Visual and motion direction (all films)

- Ask for an optional reference film, image or URL and what specifically to borrow: composition, rhythm, transitions, character treatment or typography. Also ask what to avoid. No reference is a valid answer; offer a direction grounded in the product.
- Set 2–3 mood words, pace (calm, deliberate, energetic), light/dark when both exist, and whether the film is UI-led or character-led. Ask only where discovery or the initial request leaves a meaningful choice.
- Choose words (punchlines, short captions, UI only), transitions (shared-element moves, camera moves, clean cuts), and useful extras (cursor, approved partner logos, proof, existing texture). Recommend a coherent combination instead of asking the user to art-direct every effect.

### Sound and working mode (all films)

- Silent, supplied licensed music, or a track to source? Voiceover or no voiceover? If voiceover: language, voice/tone, supplied script or permission to draft, and captions. Note any supplied assets and usage constraints. Ask about SFX only if they materially affect the direction. A muted placement must remain understandable without audio.
- **One-pass production (recommended when the user wants a complete first result):** After the brief is settled, create style frames, build, internally review and fix, then deliver without intermediate approval checkpoints.
- **Collaborative production:** Show the beat sheet, three style frames, and a mascot pose sheet when relevant; wait for feedback before building all scenes.

If the user already requested one-shot/one-pass production, record that mode without asking again. They may delegate unspecified taste choices (“you decide”); record your defaults and proceed. If they have not selected or implied a mode, ask once alongside the remaining direction questions.

## Settle and persist the brief

Write reusable identity and brand decisions to `videos/BRAND.md`; write film-specific audience, promise, story, mascot appearances, CTA and delivery choices to `videos/<film>-prompt.md`. Label decisions as user-specified, source-derived or delegated defaults, with asset paths/URLs. Keep missing required input distinct from a delegated choice.

Before scene production, summarize the creative anchor and consequential defaults in a short paragraph. Ask one focused follow-up only for unresolved decisions that would materially change the film: an undefined chosen mascot, inaccessible essential assets, conflicting requirements, missing product truth, or required audio not yet available. Do not treat silence as delegation. With a complete brief or explicit delegation, proceed in the selected mode without asking for the same approval twice.

Do not ask for colors, fonts, radius or spacing already established by the product. Do not force a mascot, proof metric, voiceover, or reference on a film that does not need it. Preserve verification and revision of actual defects in both modes.
